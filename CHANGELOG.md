# RadioPlan Pro 1.0.0

- First installable release: one-click Windows installer, Android app, flash-drive package and online version.
- Built-in project library: automatic saving, project history, backups, terrain kept with each project.
- Built-in reference data for NC, SC, GA and TN: county boundaries, towns and ZIP codes work without internet.
- Automatic updates from GitHub Releases; first-start setup that asks only for the site address.
